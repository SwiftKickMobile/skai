- 2026-08-29 **`skai-suggestion` reworded as what it is: a suggestion box.** Its description said "process improvement idea… process friction", which collided with the new `skai-process-refinement` skill on selection. It now states plainly that it captures a developer's idea, request, or complaint about the skai dev process and files it as a GitHub issue on the skai repo, and that changing a guide's content is the other skill. H1 is now "SKAI: Suggestion box"; the README Usage entry matches. Wrapper text changed, so hosts must re-run adapters. No behavior change.
- 2026-08-29 **New skill `skai-process-refinement`.** The refinement guide had no entry point — it was the only guide in `Guides/Process/` without one, and was reached by pointing an agent at the file. The guide files process tickets as GitHub issues — it says "ticket" 36 times — and its old name described improving a process, which is what `process-refinement-guide.md` does. Pointers updated in `Templates/skills/skai-suggestion/SKILL.md`, `Guides/Process/dev-retro.md` (handoff gate and transfer target), `README.md`, and `maintain-skai.md`. **`skai-suggestion`'s installed wrapper changed, so hosts must re-run adapters** — a stale wrapper points at a file that no longer exists. No behavior change.
