## SKAI

This repo uses `skai` (`Submodules/skai/`) for its development process: guided workflows installed as skills, and the policies below.

- Read `skai/integration.md` before running any build, test, or verification command. It is the project-owned source of truth for commands, destinations, and evidence collection.
- Use the installed `skai-*` skills when a request matches one of their descriptions. They live in this agent's skills folder and describe themselves.
- Prefer the canonical guides under `Submodules/skai/Guides/` over older copied guidance elsewhere in the repo.
- If instructions outside this block conflict with `skai` defaults, ask the human before proceeding.
