# SKAI: Design promotion

## Instructions

- Read `Submodules/skai/Guides/Design/design-promotion.md` in full, including its Project addendum instructions, and follow it.
- Read the tool guide it names for the project's design tool — `C1` checks the drafts against it, and `C3` places them by its rules (for Figma, `Submodules/skai/Guides/Design/figma-designer-guide.md`).
- Preserve its hard boundaries: never redesign — a draft that needs changing returns the package to authoring; change nothing in production before the Promotion Checks gate advances; never delete the change page before the supervisor has reviewed production.
