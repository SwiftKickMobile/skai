# Glossary

Terms the product specs use, and the items that govern each.

### Active suggestion
A collaborator's proposed edit that remains available for the owner to consider ([SUGGESTION-03]).

### Estimated net change
The proposed length less the removed and moved words; it does not account for other edits ([SUGGESTION-04]).

### Inbox stage
The first notebook stage, which also serves as the owner's reminder schedule ([STAGE-01-01]).

### Notebook
A collection of notes together with the collaborators invited to work on it ([NOTEBOOK-01]).

### Superseded suggestion
An earlier suggestion that a reissued edit has replaced; reported as Expired ([SUGGESTION-12]).

### Terminal stage
Archived or Deleted: a stage the owner is not expected to act on again ([STAGE-03]).

### Workflow entry
A notebook in one stage of the owner's workflow, carrying the date it reached that stage ([STAGE-04]).
