# Reminder

Stub for link resolution: the reminder items the workflow files cite.

### REMINDER-01
A reminder is a scheduled prompt to revisit a note.

### REMINDER-05
A completed reminder moves on the next calendar day.

### REMINDER-08
A reminder the sync service stops sending is kept for a retention period.

### REMINDER-19
A reminder past its scheduled time without being completed is shown as overdue.

### REMINDER-26
A reminder may be upcoming for a note in a downstream stage.
