# Suggestion Status

Stub for link resolution: the reported statuses the suggestion file cites.

### SUGGESTION-STATUS-01
The sync service may supply a reported status with a suggestion.

### SUGGESTION-STATUS-03
Accepted: the owner has applied the suggestion.

### SUGGESTION-STATUS-04
Rejected: the owner has declined the suggestion.

### SUGGESTION-STATUS-05
Expired: the suggestion's validity has ended, including by supersession.

### SUGGESTION-STATUS-06
Reverted: the suggestion was undone after it was applied.

### SUGGESTION-STATUS-07
Merged: the suggested text has become part of the note's history.
