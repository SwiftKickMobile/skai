# List Screen

Rules every list screen shares.

### UI-LIST-01
A list screen shows a [stale notice][g-stale-notice] while its contents are out of date, naming when they were last refreshed (**01**).

- **01** The notice names the time of the last refresh.

### UI-NOTES-04
A list's empty state reads `No notes yet` or `Trash is empty` with a prompt to write a note.

[g-stale-notice]: ../glossary.md#stale-notice
