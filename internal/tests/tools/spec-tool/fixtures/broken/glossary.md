 > **Also called:** iota ( ).

### Lambda term
A note whose label is not bold ([DUP-01]).

> __Also called:__ lambda (support).

### Mu term
A note carrying a link ([DUP-01]).

### Nu term
A note carrying a bare address ([DUP-01]).

> **Also called:** nu (support, WWW.EXAMPLE.COM).
