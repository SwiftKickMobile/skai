# SKAI branding

The canonical artwork is SVG, generated by [generate.swift](generate.swift):

- [Light-background wordmark](skai-logo.svg) and [dark-background wordmark](skai-logo-dark.svg), used
  by the main README.
- [Mac app icon](SKAIConfigure.icon): an Icon Composer file. Its one layer,
  `Assets/skai-app-icon-symbol.svg`, is the symbol alone on a transparent 1024 canvas; the icon's fill
  is white and the system draws the rounded square.

The flat ribbon retains its angular peaks, vertical sides and rounded cutouts. The three
straight diagonal bands have the same 200-unit perpendicular width. Opposing contours are
exact 180-degree copies; both cutouts have matching radii. Top and bottom tips use
circular fillets tangent to the adjoining straight edges. Width equality applies to the
straight bands, rather than forcing the entire silhouette into a monoline stroke.
All exports are centered using visible path bounds, not nominal drawing coordinates. Wordmark
exports have equal outer ink margins; the icon layer centers the symbol on its canvas.
Both wordmarks reuse the same symbol geometry. Letterforms are outlined, so viewing needs no font.

Palette: cyan `#009DDE` and magenta `#A1268C` from the
[SwiftKick logo](https://swiftkick.ai/assets/images/logo.svg), with their intermediate blend for the ribbon.
The symbol and wordmarks contain no shading, grain, external images or background panels. The Mac
icon's white background and Liquid Glass treatment come from `SKAIConfigure.icon`.

Regenerate with `swift generate.swift .` from this directory on a Mac (macOS 14 or later). It
rewrites the two wordmarks and the icon layer inside `SKAIConfigure.icon`; the Mac app build compiles
that file with `actool` (Xcode 26 or later) into `Assets.car` plus an ICNS fallback.

The source geometry is maintained in [generate.swift](generate.swift). Artwork edits do not change
project configuration or installed components.
